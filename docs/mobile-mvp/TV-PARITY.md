# 四端弹幕适配

本轮将原先手机专用的弹幕接入 Android、iOS、Android TV 和 tvOS。代码接入不代表四端已完成构建或设备验收，请核对当前提交的 Actions。没有发布新的 TV APK、IPA 或商店版本。

## 共用功能与范围

- 使用当前 Jellyfin 服务器的 `/api/danmu/{itemId}/raw`，保留反代前缀与已授权请求头。不搜索第三方弹幕、不修改服务端插件。
- 在线 Movie/Episode/Video 的 Direct Play 和 Direct Stream。转码、直播、离线、投屏、外部播放器和 PiP 弹幕仍不在范围内。
- 开关、字号 0.7–1.5×、不透明度 30%–100%、1–8 行、显示时长 4–12 秒、偏移 ±30 秒（0.5 秒步长）。正数提前，底部保留 30% 字幕区域。
- 外观调整不会重启影片或重新下载弹幕。设置保存在当前设备，切集和下次播放继续使用；没有新增跨设备云同步。
- 加载、空文件、认证失败、端点不可用和网络/解析错误状态；支持重试。失败不阻塞视频。
- 保留取消、超时、大小/XML 安全限制、重定向拒绝和凭据隔离。设置事件仅携带六项偏好，不携带 URL、账号或请求头。

## 各端入口

- Android/iOS 手机：控制栏弹幕开关与设置按钮，原生全屏设置面板。
- Android TV 原生：更多 → 弹幕设置。方向键选择字段和值，返回逐级退出，关闭回到上一层。MPV 与 ExoPlayer 的 DirectPlay/DirectStream 均接入；Exo 使用当前媒体的主线程实时位置，非每秒缓存。
- tvOS 26+ 原生：更多 → 弹幕设置。独立焦点层提供开关、加减、状态与重试；Menu/关闭恢复播放控制栏。旧版 tvOS 使用既有 React 播放器路径。
- 两种 TV 的旧版 React MPV：控制栏气泡按钮打开导航式弹幕设置页。遥控操作不会同时触发影片快进，Back/Menu 先关闭设置。设置页面也有 TV 加减按钮。

Android 手机原生 Exo 与旧版 React Exo 未新增弹幕，选择 MPV 获得上述能力。不同引擎能力不能用同名开关代替实际支持。

## 验证与构建

本地可执行：Java 生产核心、Android overlay 的 focused Kotlin/API 编译、JS 组件/设置/门禁/重复打开/Back/后台/切集清理回归，以及 Android TV/tvOS 源码契约检查。源码契约检查不执行 Compose、UIKit 或 SwiftUI。

新增 CI 矩阵使用同一提交分别预生成并完整编译 Android phone、Android TV、iOS 和 tvOS；Apple runner 另跑 Swift 核心与遥控数值边界测试。编译不使用签名凭据，不上传 App/APK 或发布 Release。当前云工作区没有 Xcode/Swift SDK，因此不能把本地检查描述为 Apple 完整编译通过。

## 必须完成的设备验收

1. 四端分别用合成 XML 与临时服务器验证滚动/顶部/底部弹幕，核对字幕、HDR、画面缩放及长中文/Unicode 文本。
2. 暂停、续播、前后拖动、0.5×/1×/2×、缓冲、快速切集和换源时不残留上一视频弹幕。
3. TV 连续按键、字段上下限、偏移长列表、重复开关设置、Back/Menu、播放/暂停键、后台与恢复。设置打开期间不穿透快进或抢播放焦点。
4. 关闭后重新播放、跨剧集及重启应用确认偏好保持；默认值与范围在四端一致。
5. 空/缺失 XML、401/403/404、断网、重试、取消和恶意 XML。观察是否有旧请求晚到污染新视频。
6. Android TV 分别测试 MPV 与 Exo，tvOS 分别测试原生及旧版 React 路径。使用当前提交构建，不能以手机构建替代 TV 构建。
