# Asterfin

基于 [Streamyfin](https://github.com/streamyfin/streamyfin) 的 Android / iOS Jellyfin 客户端分支，增加服务端 XML 弹幕支持。非 Jellyfin 或 Streamyfin 官方发行版。

**开发中，暂无已验证的 Asterfin APK / IPA，尚未完成真机验收。**

- [当前代码与功能说明](https://github.com/z979054461/asterfin/tree/mobile-dev)
- [开发起步](https://github.com/z979054461/asterfin/blob/mobile-dev/START-HERE.zh-CN.md)
- [参与开发与反馈说明](CONTRIBUTING.md)

当前开发在 `mobile-dev` 分支；此 `develop` 分支保留上游基线，不是本分支新功能的构建入口。

本仓库暂未开放 Issues 或 Discussions。代码改进可提交 [Pull Request](https://github.com/z979054461/asterfin/pulls)，其他反馈请等待本仓库开放渠道，不要提交给上游。安全问题见 [SECURITY.md](SECURITY.md)。
