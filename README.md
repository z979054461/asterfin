# Jellyfin Mobile

基于 [Streamyfin](https://github.com/streamyfin/streamyfin) 的 Android / iOS Jellyfin 客户端分支，增加服务端 XML 弹幕支持。非 Jellyfin 或 Streamyfin 官方发行版。

**开发中，暂无本分支发布的 APK / IPA，尚未完成真机验收。**

- [当前代码与功能说明](https://github.com/z979054461/jellyfin-mobile/tree/mobile-dev)
- [开发起步](https://github.com/z979054461/jellyfin-mobile/blob/mobile-dev/START-HERE.zh-CN.md)
- [问题反馈](https://github.com/z979054461/jellyfin-mobile/issues)

当前开发在 `mobile-dev` 分支；此 `develop` 分支保留上游基线，不是本分支新功能的构建入口。
